# Daily Fortune Oracle · 婆婆送福

香港打小人体验的手机端数字祝福延续。基于 2026-06-18 的原网页迭代，保留二维码入口、称呼、六种祝福主题、三色祝福卡和音效；仅保留掷筊问运，已移除摇签。新增可选的摄像头抬手、放下投掷。

## 运行

安装依赖：`pnpm install`。本地预览：`pnpm dev`。逻辑测试：`pnpm test`。发布文件：`pnpm build`，产物在 `dist/`。

## 流程与判定

净手与禀报以文字引导；称呼选填，不收集年龄或地址。静候十秒可跳过。点击投掷后锁定操作，落定一次只记录一次结果。重新静心会取消上一流程的计时和待处理动画。摄像头手势只在可投掷的步骤生效。

- 圣筊：一平一凸；笑筊：两平；阴筊：两凸。
- 一次定乾坤：一轮一次，只有圣筊通过。
- 三次取多数：完整三次，至少两次圣筊通过；不会在前两次提前结算。
- 三圣杯才算：必须连续三次圣筊，笑筊或阴筊清零连续次数。用户可提前停止收下安慰祝福，界面不会声称已通过。
- 特殊落地：每次模拟 1% 立筊、1% 落出范围，终止该轮且不判定通过。正常落地时两片分别等概率选平/凸。这是为互动设计的模拟概率，不是物理测量或民俗依据。
- 不通过不自动重掷，也不改写实际筊象。

大吉、吉、小吉是本项目创作祝福，不是传统固定筊象换算。单次应允或连续三圣筊为大吉；多数规则两次圣筊为吉、三次为大吉；笑筊以吉安慰，其余未通过以小吉鼓励。

## 文化与视觉

参考旧对话「香港打小人故事流程」：放下烦恼 → 婆婆送福 → 摘下 VR 眼镜 → 手机扫码带走祝福。掷筊与香港打小人明确作为本项目串联的不同民俗实践，不声称属于同一传统仪式。文化判读参考 https://www.tad.gov.tw/m1.aspx?sNo=0027010 及用户提供的地方规则。

视觉：依据本轮三张参考，改为珊瑚红、奶油白、淡粉与酒红文字，使用朱红木质筊杯；祝福卡采用桃粉/薄荷/柠黄的糖果配色和对比边框。保留原 logo 与筊杯图像。固定 430px 手机竖屏，电脑同样居中显示手机版。支持中英切换，覆盖界面、文化说明、结果和导出的 PNG。保留输入的名字与自定义问题原文。支持减少动画、减少透明、键盘、对话框焦点与可读结果提示。

## 摄像头手势

点击开启后才调用 getUserMedia，仅 video、不请求 audio。前置摄像头画面镜像显示；MediaPipe HandLandmarker 0.10.21 在本机识别 21 个手部关键点，CPU 推理上限 8 帧/秒。只处理当前帧，不录制、不上传。库、WASM、模型均随网站托管，不依赖运行时 Google 或 CDN 请求。

动作起点按用户手部自然高度校准（稳定 180ms），抬高至少画面高度的 9% 即准备投掷，不必在最高处停顿。相对最高点下降 4.5%–8%（随抬高手幅度调整）并在下一帧确认，或一次明显下降 12%，即触发投掷。短暂丢失跟踪最多容忍 650ms，丢失本身不触发。抬起后五秒内放下有效；静止抖动、切换手和重置不触发。在 setup、ready 或仍需继续的 outcome 状态接受手势；输入框编辑中及打开对话框时暂停。setup 的第一次手势自动读取当前问题与规则并开始本轮，不必再找开始按钮。手势投掷完成本轮后，短暂展示筊象并自动进入今日祝福；尚未完成三次或连续三圣筊规则时，滚动显示进度。按钮投掷保留原来的手动查看结果流程。

关闭、完成祝福、切到后台或离开页面会停止视频轨道并释放识别器。权限拒绝、设备缺失、加载失败均显示双语提示，保留按钮路径。用户取消后才到达的授权也会立即关闭轨道。

验证：手势时序单元测试，摄像头拒绝/迟到授权/后台停止的模拟生命周期测试，以及原有规则与双语文案测试。没有使用用户的真实摄像头做实机识别测试。
